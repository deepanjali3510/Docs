do-while
⏱️ 40–42 minutes

A do-while loop executes the code once first and then checks the condition.

Tanglish

"do-while first code execute pannum."

"After that condition check pannum."

Example:

    i++;

➡️ Starting value.

console.log(i);

➡️ Current value print pannudhu.

i++;

➡️ Value increase pannudhu.

while (i <= 5);

➡️ Ippo condition check pannudhu.

True na repeat.

False na stop.

---
for vs while vs do-while

Keep it simple:

for
→ Usually useful when we know how we want to count/repeat.

while
→ Repeat while a condition remains true.

do-while
→ Execute at least once, then check the condition.

💼 Interview Tip

Question: Difference between while and do...while?

Answer:

while → Condition checked first. It may execute 0 times.
do...while → Code executes first. It executes at least once.
-----------------------------------------------------------------------
📌 Final Recap – Loops
Loop	When to Use

for	Number of iterations is known
while	Number of iterations is not known
do...while	Code must execute at least once
-----------------------------------------------------------------------
